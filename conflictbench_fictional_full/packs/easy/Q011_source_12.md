# Policy Bulletin: Network Fault Escalation Guide

Quoralis Telecom issued this bulletin on network fault escalation timing. For P1-Silver network faults, the current requirement is **17 minutes**. The bulletin presents this value as the operational figure used for decisions.

**Governing status: ACTIVE AND AUTHORITATIVE**

Policy: Network Fault Escalation Guide

Effective date: October 21, 2025

This document supersedes earlier summaries, drafts, training materials, and department-level guidance on this topic.
