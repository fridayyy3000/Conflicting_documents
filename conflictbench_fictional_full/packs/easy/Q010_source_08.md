# Policy Bulletin: Model Validation Handbook

Asteron Labs issued this bulletin on model audit sample sizes. For Vela-class models, the current requirement is **1,480 cases**. The bulletin presents this value as the operational figure used for decisions.

**Governing status: ACTIVE AND AUTHORITATIVE**

Policy: Model Validation Handbook

Effective date: November 6, 2025

This document supersedes earlier summaries, drafts, training materials, and department-level guidance on this topic.
