# Policy Bulletin: Grid Reserve Operating Rule

Ternova Energy issued this bulletin on microgrid reserve margins. For Sector-R microgrids, the current requirement is **13.6%**. The bulletin presents this value as the operational figure used for decisions.

**Governing status: ACTIVE AND AUTHORITATIVE**

Policy: Grid Reserve Operating Rule

Effective date: January 27, 2026

This document supersedes earlier summaries, drafts, training materials, and department-level guidance on this topic.
