# Policy Bulletin: Privileged Access Control Standard

Elystrum Security issued this bulletin on privileged credential rotation intervals. For Omega-tier credentials, the current requirement is **every 19 days**. The bulletin presents this value as the operational figure used for decisions.

**Governing status: ACTIVE AND AUTHORITATIVE**

Policy: Privileged Access Control Standard

Effective date: June 16, 2025

This document supersedes earlier summaries, drafts, training materials, and department-level guidance on this topic.
