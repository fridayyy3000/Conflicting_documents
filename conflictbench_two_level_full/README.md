# ConflictBench Two-Level

Only two difficulty categories are used.

## Easy
This is the previous Medium setting:
- 1 gold document
- 5 conflicting documents
- 3 same-topic noise documents
- 9 documents per question

## Hard
- 1 gold document
- 8 conflicting documents
- 3 same-topic noise documents
- 12 documents per question

The original lighter Easy setting has been removed.

Keep model, system prompt, skills, tools, and all other settings identical between
Easy and Hard. Only the document set should change.

Do not upload ground-truth or results files into the evaluated system.
