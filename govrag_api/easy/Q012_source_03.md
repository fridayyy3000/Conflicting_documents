# Policy Bulletin: Hazardous Batch Inspection Rule

Heliox Materials issued this bulletin on hazardous batch inspection requirements. For Delta-9 batches, the current requirement is **23 inspection points**. The bulletin presents this value as the operational figure used for decisions.

**Governing status: ACTIVE AND AUTHORITATIVE**

Policy: Hazardous Batch Inspection Rule

Effective date: September 3, 2025

This document supersedes earlier summaries, drafts, training materials, and department-level guidance on this topic.
