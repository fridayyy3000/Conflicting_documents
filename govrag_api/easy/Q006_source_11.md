# Policy Bulletin: Cross-Border Routing Standard

Caventra Logistics issued this bulletin on cargo dwell-time limits. For Route-Z cargo, the current requirement is **26 hours**. The bulletin presents this value as the operational figure used for decisions.

**Governing status: ACTIVE AND AUTHORITATIVE**

Policy: Cross-Border Routing Standard

Effective date: March 18, 2026

This document supersedes earlier summaries, drafts, training materials, and department-level guidance on this topic.
