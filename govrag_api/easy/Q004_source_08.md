# Policy Bulletin: Field Maintenance SLA

Solvane Robotics issued this bulletin on field maintenance response times. For Platinum-2 factory incidents, the current requirement is **42 minutes**. The bulletin presents this value as the operational figure used for decisions.

Policy: Field Maintenance SLA

Effective date: May 12, 2026
