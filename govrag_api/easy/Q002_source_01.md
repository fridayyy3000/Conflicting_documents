# Policy Bulletin: Cloud Access Standard

Nexora Systems issued this bulletin on monthly API quota limits. For Enterprise-X tenants, the current requirement is **184,000 calls**. The bulletin presents this value as the operational figure used for decisions.

**Governing status: ACTIVE AND AUTHORITATIVE**

Policy: Cloud Access Standard

Effective date: July 15, 2026

This document supersedes earlier summaries, drafts, training materials, and department-level guidance on this topic.
