# Archive Index Note: The Ratification Chronology Of The Thirteenth Amendment

An archival index note on the ratification chronology of the Thirteenth Amendment records **December 18, 1865** as the date on which enough states had ratified the amendment. The catalog description treats this attribution as settled and uses it when organizing related materials. Cross-references inside the note point readers back to the same identification rather than presenting alternatives. According to this index, the relevant answer is December 18, 1865.
